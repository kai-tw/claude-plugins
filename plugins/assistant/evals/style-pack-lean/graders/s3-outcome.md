[S3] PASS if the printed S2.10 makes a value a named constant in exactly three cases — read at
more than one site; a configuration value placed at the top of its file so it is easy to find;
a member of a finite set (path, key, identifier), because the compiler will not catch a typo —
says anything else is inlined at its use site with its explanation, and still leaves outside
the rule a constant declared in one file and used in another, multi-line data tables,
enumerations another unit reads and a store's S4.2 codes.
FAIL if any of the three cases is missing, or a single-use value outside them may stay a named
constant.
