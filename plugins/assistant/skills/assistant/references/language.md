# 中文的寫法

Kai 2026-09-21 定的規則，原文：「請使用符合意境的正體中文、台灣在地化之中文詞彙、
文法，嚴禁直翻，專有名詞除非沒有對應的台灣專業術語之中文翻譯，否則請一律使用原文。」

**所管**：本 plugin 產出的每一段給人讀的中文——任務書、決策簡報、交付摘要、agent 的
報告、chat、commit message 與 PR 內文。app 內的使用者可見字串**不在此列**，那是
`ui-text-pack`（U3 由各語系自行成文，判準相同、法源不同）。

- **正體中文，台灣的詞與語序.** 記憶體不是內存、預設不是默認、品質不是質量、水準不是
  水平、程式不是程序、回報不是反饋。
- **嚴禁直翻.** 英文詞逐字轉成中文另造新詞者，一律改寫——「腿名」不是中文。判準只有
  一個：母語者會不會這樣說。
- **專有名詞：沒有台灣業界通行的中譯就用原文.** `worktree`、`cache`、`stack trace`、
  `predicate`、`lint` 保留原文；有通行譯法的就譯（函式、變數、相依、部署、字串）。
  自創中譯與冷僻行話同為違規：前者要讀者反推原文，後者讓讀者無從反推。
